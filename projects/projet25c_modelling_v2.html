ADARP

Modelling layer of the ADARP analysis. Combines multilevel ordinal cumulative modelling (frequentist clmm + Bayesian brms cumulative family) with predictive machine learning (ElasticNet vs LightGBM, leave-one-subject-out cross-validation). Uses Curran-Bauer decomposition of physiological features into within-subject (_wz) and between-subject (_bm) components to disentangle state-like and trait-like effects on momentary stress. Hierarchical model comparison (null → +_wz → +_bm → +covariates) quantifies incremental contribution of each predictor block. Predictive models are interpreted with DALEX permutation importance and Shapley values. Built on the tidymodels ecosystem with explicit caveats on sample-size-driven uncertainty.

1 1. From features to inference

Phases 15a and 15b produced an analysis-ready table: 99 EMA prompts × 99 columns (raw signals → 21 physiological features × 3 versions: raw, within-subject z-score, between-subject mean), with explicit quality-control flags at session, window, and feature level. 58 windows pass the data-engineering QC; 46 of those also pass the feature-extraction QC. After excluding 1 subject with only 1 EMA (insufficient for within-subject standardisation, see Section 2), the analytic sample for modelling is 44 EMA windows clustered in 7 subjects. This phase asks the substantive question: do those features predict momentary stress?

The outcome is the ordinal stress_composite score (sum of three binary indicators: more_stressed, more_overwhelmed, more_anxious; range 0–3). Two reasons drive this choice over the binary stress_event:

  1. The binary outcome is 80/12 imbalanced in the public ADARP release because the stress-events file collected prompts triggered by moments of self-reported stress; pure logistic regression on this would mostly model the prompting protocol.
  2. The composite score distributes more usefully: 1 / 16 / 31 / 49 across categories 0–3, giving room for both ordinal multilevel modelling and reasonable predictive ML.

The modelling proceeds in two complementary tracks:

  • Track A: hierarchical multilevel ordinal modelling — explanatory inference. Builds a sequence of cumulative-link mixed models from null → predictor blocks, quantifying how much variance each block resolves and which features carry signal after accounting for random effects.
  • Track B: predictive machine learning — ElasticNet vs LightGBM with leave-one-subject-out cross-validation. Asks the practical question: given a new EMA prompt and its preceding 30 min of physiology, how well can we predict the stress score?

Both tracks share the same input table and the same Curran-Bauer decomposition (within-subject _wz, between-subject _bm), making direct interpretation possible.

3 3. Multilevel ordinal modelling

We build a hierarchy of cumulative-link mixed models. Each adds one block of predictors and is compared against its predecessor on AIC (frequentist) and posterior predictive criteria (Bayesian).

The base specification:

\[ P(Y_{ij} \le k) = \text{logit}^{-1}(\theta_k - \eta_{ij}), \quad k \in \{0, 1, 2\} \]

with \(\eta_{ij}\) the linear predictor for prompt \(i\) in subject \(j\), including a subject-level random intercept \(u_j \sim \mathcal{N}(0, \sigma_u^2)\). The proportional-odds assumption is checked at the end of the section.

# anova.clmm() has a known issue with formulas built via as.formula(paste(...))
# (it cannot re-evaluate the model calls). We compute the LRT manually:
#   LRT = 2 * (logLik_full - logLik_reduced)
#   df  = n_params_full - n_params_reduced
#   p   = pchisq(LRT, df, lower.tail = FALSE)

manual_lrt <- function(m_reduced, m_full, label) {
  ll_r <- as.numeric(logLik(m_reduced))
  ll_f <- as.numeric(logLik(m_full))
  df_r <- attr(logLik(m_reduced), "df")
  df_f <- attr(logLik(m_full),    "df")
  lrt  <- 2 * (ll_f - ll_r)
  ddf  <- df_f - df_r
  pval <- if (ddf > 0 && lrt >= 0) pchisq(lrt, df = ddf, lower.tail = FALSE) else NA_real_
  tibble::tibble(
    comparison      = label,
    logLik_reduced  = round(ll_r, 2),
    logLik_full     = round(ll_f, 2),
    df_reduced      = df_r,
    df_full         = df_f,
    LRT_chisq       = round(lrt, 3),
    df_diff         = ddf,
    p_value         = round(pval, 4)
  )
}

4 4. Predictive ML: ElasticNet vs LightGBM with leave-one-subject-out CV

The MLM in Section 3 asks: “given the curated top-10 features, can we infer subject-level effects?” The ML in this section asks the complementary question: “given the full pool of state-level (_wz) features and time-of-day covariates, how well can we predict the ordinal stress score for a held-out subject?”

The pool is restricted to the 21 within-subject features plus databurst_f and time_of_day_h (24 predictors), based on three considerations:

  • Substantive: Section 3 showed that trait-level (_bm) features did not improve fit over null, consistent with the very low ICCs observed for HRV in phase 15b. We focus on state-like signal.
  • Statistical: at n = 44 with 7 subjects in LOSO-CV, including 42 features pushes us into the n ≈ p regime where even regularised models become unstable. ElasticNet’s intrinsic regularisation handles 24 predictors gracefully; pushing to 42 would be optimistic.
  • Methodological coherence: this avoids the post-selection inference issue (we never feed LASSO-selected features to the MLM). ElasticNet here is a stand-alone predictive method, not a feature selection tool for downstream inference.

4.2 4.2 ElasticNet ordinal regression

ordinalNet fits a regularised proportional-odds model with elastic- net penalty. We use alpha = 0.5 (equal mix of L1 and L2) and let the package choose lambda automatically by AIC within each fold.

predict_enet_one_fold <- function(fold, data, features) {
  X_tr <- as.matrix(model.matrix(~ . - 1,
                                 data[fold$train, c(features, "databurst_f", "time_of_day_h")]))
  X_te <- as.matrix(model.matrix(~ . - 1,
                                 data[fold$test,  c(features, "databurst_f", "time_of_day_h")]))
  y_tr <- data$stress_composite_ord[fold$train]
  y_te <- data$stress_num[fold$test]

  fit <- tryCatch(
    ordinalNet(X_tr, y_tr,
               family = "cumulative", link = "logit",
               alpha = 0.5, parallelTerms = TRUE,
               nLambda = 30),
    error = function(e) NULL,
    warning = function(w) suppressWarnings(
      ordinalNet(X_tr, y_tr,
                 family = "cumulative", link = "logit",
                 alpha = 0.5, parallelTerms = TRUE,
                 nLambda = 30)
    )
  )
  if (is.null(fit)) {
    return(tibble::tibble(true = y_te, pred = NA_real_))
  }

  # Predict class probabilities; convert to expected ordinal value
  probs <- predict(fit, newx = X_te, type = "response")
  if (is.list(probs) && !is.null(probs$probs)) probs <- probs$probs
  if (is.matrix(probs) && ncol(probs) == nlevels(y_tr)) {
    levels_num <- as.numeric(levels(y_tr))
    expected   <- as.numeric(probs %*% levels_num)
  } else {
    expected <- rep(NA_real_, length(y_te))
  }
  tibble::tibble(true = y_te, pred = expected)
}

compute_metrics <- function(df, model_name) {
  ok <- !is.na(df$pred) & !is.na(df$true)
  if (sum(ok) < 5) {
    return(tibble::tibble(model = model_name, n = sum(ok),
                          rmse = NA_real_, mae = NA_real_,
                          spearman_rho = NA_real_,
                          weighted_kappa = NA_real_))
  }
  d <- df[ok, ]
  rmse <- sqrt(mean((d$pred - d$true)^2))
  mae  <- mean(abs(d$pred - d$true))
  rho  <- suppressWarnings(cor(d$pred, d$true, method = "spearman"))
  # Weighted kappa requires integer predictions
  d$pred_int <- round(pmin(pmax(d$pred, 0), 3))
  kappa <- tryCatch({
    if (requireNamespace("psych", quietly = TRUE)) {
      psych::cohen.kappa(cbind(d$true, d$pred_int))$weighted.kappa
    } else NA_real_
  }, error = function(e) NA_real_)
  tibble::tibble(model = model_name, n = sum(ok),
                 rmse = round(rmse, 3),
                 mae  = round(mae,  3),
                 spearman_rho   = round(rho,   3),
                 weighted_kappa = round(kappa, 3))
}

6 6. Limits, transparency, and the bridge to phase 15d

The honest summary of phase 15c is nuanced. At n = 44 EMA windows clustered in 7 subjects, with the public ADARP release restricted to the Stress Events file rather than the full 4-prompts-per-day EMA web survey, the physiological feature set extracted in phase 15b does not yield strong inferential signal at conventional α. The MLM in Section 3 found no fixed-effect block significantly improving over the null random-intercept model with well-defined standard errors. However, the predictive ML in Section 4 paints a slightly richer picture: while ElasticNet shrinks to the subject-mean baseline, LightGBM departs from that floor (weighted κ moves from −0.67 to +0.15, Spearman ρ from −0.62 to ≈ 0), and DALEX permutation importance places the EDA tonic block (eda_scl_mean_wz, eda_scl_slope_wz) at the top of the predictive ranking — a finding consistent with the autonomic stress literature, where sustained sympathetic arousal is most reliably reflected in tonic skin conductance.

The reconciliation between the two tracks is methodologically informative:

  • MLM tests whether a coefficient is non-zero given the model structure. With 44 observations clustered in 7 subjects (between- subject ICC ≈ 0.88 on the latent scale), almost all variance in the outcome is absorbed by subject identity, leaving very little residual to anchor a fixed-effect estimate. This is a power limitation, not an absence of biological signal.
  • ML asks how well one can recover the outcome from features, with regularisation that depends on the model class. ElasticNet’s L1 penalty zeros out predictors below an effect-size threshold and thus matches the MLM null. LightGBM’s tree splits, by contrast, can capture local non-linear dependencies that the linear MLM cannot see — and the consistency between LightGBM’s top features (EDA tonic) and the literature suggests the captured signal is not a pure overfit.

Three reasons make this combined picture informative rather than disappointing:

  1. Bounded inference plus a directional hypothesis. The clmm and brms posteriors yield explicit, wide bounds on the magnitude of any physio→stress effect at this n. The LightGBM importance ranking offers a directional hypothesis for which features are most worth scaling up the data collection on (EDA tonic, secondarily HRV non-linear and HF).
  2. Diagnostic on the data itself. The outcome ICC ≈ 0.88 (Section 3.5) and the strong baseline-subject-mean floor in LOSO (Section 4) jointly imply that subject identity dominates stress-score variance — which is the classic argument for more subjects, not better features.
  3. Comparison with the dataset’s source publications. Alinia et al. (2021), the original team behind the ADARP dataset, performed day-level Spearman correlations between EDA/HRV features and self- reported stress on the full 343-EMA collection (of which our public subset is the 99 stress-flagged events). Their strongest reported associations reached |ρ| ≈ 0.34, with most physio-stress correlations in the |ρ| ≈ 0.20–0.30 range — modest by absolute standards. Importantly, they explicitly identified the absence of multilevel modelling as a limitation, noting that “more sophisticated multilevel modeling of these associations […] might provide additional insights about within-person associations as well as between-person differences.” The MLM track of this analysis directly addresses that limitation. Our null result at n = 44 is therefore not in conflict with the literature: it is the within-subject decomposition of an effect that was already known to be weak at the day-aggregated level in the full sample.
  4. Pipeline correctness was the deliverable. Phases 15a–15c demonstrate that the full chain — raw multimodal wearable + EMA → synchronisation → feature extraction → inference + prediction — runs end-to-end with correct method choices, defensible QC, and honest interpretation. That deliverable holds independent of the effect-detection magnitude.

A note on the binary alternative. A natural variant of the analysis would model the binary stress_event outcome (rather than the ordinal composite) with logistic mixed models and AUC-based ML evaluation. We deliberately did not pursue this for two reasons. First, the public ADARP release restricts EMAs to the Stress Events file, where prompts are triggered by moments of self-reported stress; the binary outcome is therefore close to tautological with the act of clicking the EMA prompt itself. Second, with only 12/92 negative cases (an 80/12 imbalance) clustered in 7 subjects, leave-one-subject-out folds would contain wildly unbalanced positive/negative ratios, making AUC and balanced-accuracy estimates extremely unstable at this n.  Standard remedies for class imbalance — PR-AUC reporting, F1-optimal threshold selection via nested cross-validation, or class-weight adjustment in the loss function — would address the metric side of the problem but not the underlying structural issue: the public release does not contain the unflagged surveys that would form a genuine negative class.Re-visiting the binary outcome would require either the full 4-prompts-per-day EMA web survey (currently not in the public release) or a substantially larger cohort.

The logical next step is Phase 25d: a parametric bootstrap extension which explicitly asks the following question: “Given effects of the magnitude estimated here, how many subjects and EMA would be required to detect the smallest non-zero block with 80% power?” Such an analysis transforms the null result into practical recommendations for the design of an outpatient protocol in addiction medicine, for example

The phase 25d notebook will:

  • Simulate n_synthetic subjects with the same observed feature-stress structure but at 2×, 5×, 10× the original cohort size

## 1. From features to inference

Phases 15a and 15b produced an analysis-ready table: 99 EMA prompts
× 99 columns (raw signals → 21 physiological features × 3 versions:
raw, within-subject z-score, between-subject mean), with explicit
quality-control flags at session, window, and feature level. **58
windows pass the data-engineering QC**; **46 of those also pass the
feature-extraction QC**. After excluding 1 subject with only 1 EMA (insufficient 
for within-subject standardisation, see Section 2), the analytic sample for
modelling is **44 EMA windows clustered in 7 subjects**. This phase asks the 
substantive question: **do those features predict momentary stress?**

The outcome is the ordinal `stress_composite` score (sum of three
binary indicators: more_stressed, more_overwhelmed, more_anxious;
range 0–3). Two reasons drive this choice over the binary
`stress_event`:

1. The binary outcome is **80/12 imbalanced** in the public ADARP
   release because the stress-events file collected prompts
   *triggered by* moments of self-reported stress; pure logistic
   regression on this would mostly model the prompting protocol.
2. The composite score **distributes more usefully**: 1 / 16 / 31 /
   49 across categories 0–3, giving room for both ordinal multilevel
   modelling and reasonable predictive ML.

The modelling proceeds in two complementary tracks:

- **Track A: hierarchical multilevel ordinal modelling** — explanatory
  inference. Builds a sequence of cumulative-link mixed models from
  null → predictor blocks, quantifying how much variance each block
  resolves and which features carry signal *after* accounting for
  random effects.
- **Track B: predictive machine learning** — ElasticNet vs LightGBM
  with leave-one-subject-out cross-validation. Asks the practical
  question: given a new EMA prompt and its preceding 30 min of
  physiology, how well can we predict the stress score?

Both tracks share the same input table and the same Curran-Bauer
decomposition (within-subject `_wz`, between-subject `_bm`), making
direct interpretation possible.

## 3. Multilevel ordinal modelling

We build a hierarchy of cumulative-link mixed models. Each adds one
block of predictors and is compared against its predecessor on AIC
(frequentist) and posterior predictive criteria (Bayesian).

The base specification:

$$
P(Y_{ij} \le k) = \text{logit}^{-1}(\theta_k - \eta_{ij}), \quad k \in \{0, 1, 2\}
$$

with $\eta_{ij}$ the linear predictor for prompt $i$ in subject $j$,
including a subject-level random intercept $u_j \sim \mathcal{N}(0,
\sigma_u^2)$. The proportional-odds assumption is checked at the end
of the section.

### 3.1 Model 0 — null (random intercept only)

Quantifies the share of outcome variance that is purely
between-subject (the **outcome ICC**). High outcome ICC means
"different people have different baseline stress reports", which
shrinks the effective n for within-subject prediction.

```{r}

#| code-summary: "Manual likelihood-ratio tests between nested models (avoids anova.clmm bug)"

# anova.clmm() has a known issue with formulas built via as.formula(paste(...))
# (it cannot re-evaluate the model calls). We compute the LRT manually:
#   LRT = 2 * (logLik_full - logLik_reduced)
#   df  = n_params_full - n_params_reduced
#   p   = pchisq(LRT, df, lower.tail = FALSE)

manual_lrt <- function(m_reduced, m_full, label) {
  ll_r <- as.numeric(logLik(m_reduced))
  ll_f <- as.numeric(logLik(m_full))
  df_r <- attr(logLik(m_reduced), "df")
  df_f <- attr(logLik(m_full),    "df")
  lrt  <- 2 * (ll_f - ll_r)
  ddf  <- df_f - df_r
  pval <- if (ddf > 0 && lrt >= 0) pchisq(lrt, df = ddf, lower.tail = FALSE) else NA_real_
  tibble::tibble(
    comparison      = label,
    logLik_reduced  = round(ll_r, 2),
    logLik_full     = round(ll_f, 2),
    df_reduced      = df_r,
    df_full         = df_f,
    LRT_chisq       = round(lrt, 3),
    df_diff         = ddf,
    p_value         = round(pval, 4)
  )
}

lrt_table <- bind_rows(
  manual_lrt(m0_clmm, m1_clmm, "M0 -> M1 (adding WZ)"),
  manual_lrt(m1_clmm, m2_clmm, "M1 -> M2 (adding BM)"),
  manual_lrt(m2_clmm, m3_clmm, "M2 -> M3 (adding covars)")
)

lrt_table %>%
```

### 3.4 Bayesian sensitivity check with brms

The frequentist clmm gives point estimates and Wald CIs; brms with
`cumulative` family produces full posteriors, which carry richer
uncertainty information at this small sample size. We refit the
AIC-best specification with weakly-informative priors and verify
posterior agreement on direction and magnitude.


## 4. Predictive ML: ElasticNet vs LightGBM with leave-one-subject-out CV

The MLM in Section 3 asks: "given the curated top-10 features, can we
infer subject-level effects?" The ML in this section asks the
complementary question: "given the full pool of state-level (`_wz`)
features and time-of-day covariates, how well can we *predict* the
ordinal stress score for a held-out subject?"

The pool is restricted to the 21 within-subject features plus
`databurst_f` and `time_of_day_h` (24 predictors), based on three
considerations:

- **Substantive**: Section 3 showed that trait-level (`_bm`) features
  did not improve fit over null, consistent with the very low ICCs
  observed for HRV in phase 15b. We focus on state-like signal.
- **Statistical**: at n = 44 with 7 subjects in LOSO-CV, including 42
  features pushes us into the n ≈ p regime where even regularised
  models become unstable. ElasticNet's intrinsic regularisation
  handles 24 predictors gracefully; pushing to 42 would be optimistic.
- **Methodological coherence**: this avoids the post-selection
  inference issue (we never feed LASSO-selected features to the MLM).
  ElasticNet here is a stand-alone predictive method, not a feature
  selection tool for downstream inference.

### 4.2 ElasticNet ordinal regression

`ordinalNet` fits a regularised proportional-odds model with elastic-
net penalty. We use `alpha = 0.5` (equal mix of L1 and L2) and let
the package choose `lambda` automatically by AIC within each fold.

```{r}
#| label: en-loso
#| code-summary: "ElasticNet ordinal: LOSO predictions"
#| cache: true

predict_enet_one_fold <- function(fold, data, features) {
  X_tr <- as.matrix(model.matrix(~ . - 1,
                                 data[fold$train, c(features, "databurst_f", "time_of_day_h")]))
  X_te <- as.matrix(model.matrix(~ . - 1,
                                 data[fold$test,  c(features, "databurst_f", "time_of_day_h")]))
  y_tr <- data$stress_composite_ord[fold$train]
  y_te <- data$stress_num[fold$test]

  fit <- tryCatch(
    ordinalNet(X_tr, y_tr,
               family = "cumulative", link = "logit",
               alpha = 0.5, parallelTerms = TRUE,
               nLambda = 30),
    error = function(e) NULL,
    warning = function(w) suppressWarnings(
      ordinalNet(X_tr, y_tr,
                 family = "cumulative", link = "logit",
                 alpha = 0.5, parallelTerms = TRUE,
                 nLambda = 30)
    )
  )
  if (is.null(fit)) {
    return(tibble::tibble(true = y_te, pred = NA_real_))
  }

  # Predict class probabilities; convert to expected ordinal value
  probs <- predict(fit, newx = X_te, type = "response")
  if (is.list(probs) && !is.null(probs$probs)) probs <- probs$probs
  if (is.matrix(probs) && ncol(probs) == nlevels(y_tr)) {
    levels_num <- as.numeric(levels(y_tr))
    expected   <- as.numeric(probs %*% levels_num)
  } else {
    expected <- rep(NA_real_, length(y_te))
  }
  tibble::tibble(true = y_te, pred = expected)
}

enet_preds <- bind_rows(
  lapply(seq_along(loso_folds), function(i) {
    pred_df <- predict_enet_one_fold(loso_folds[[i]], ml_data, ml_features)
    pred_df$fold <- names(loso_folds)[i]
    pred_df
  })
)

cat("ElasticNet LOSO predictions:", sum(!is.na(enet_preds$pred)), "/",
```

### 4.3 LightGBM regression

LightGBM is run as continuous regression on the integer outcome 0-3,

respecting the ordinal nature.

```{r}

predict_lgbm_one_fold <- function(fold, data, features) {
  X_tr <- as.matrix(model.matrix(~ . - 1,
                                 data[fold$train, c(features, "databurst_f", "time_of_day_h")]))
  X_te <- as.matrix(model.matrix(~ . - 1,

    objective = "regression",
    metric = "rmse",
    learning_rate = 0.05,
    num_leaves = 7,
    min_data_in_leaf = 5,
    feature_fraction = 0.7,
    bagging_fraction = 0.7,
    bagging_freq = 1,
    verbosity = -1
```

```{r}
#| label: ml-metrics
#| code-summary: "Compute LOSO performance metrics for both models"

compute_metrics <- function(df, model_name) {
  ok <- !is.na(df$pred) & !is.na(df$true)
  if (sum(ok) < 5) {
    return(tibble::tibble(model = model_name, n = sum(ok),
                          rmse = NA_real_, mae = NA_real_,
                          spearman_rho = NA_real_,
                          weighted_kappa = NA_real_))
  }
  d <- df[ok, ]
  rmse <- sqrt(mean((d$pred - d$true)^2))
  mae  <- mean(abs(d$pred - d$true))
  rho  <- suppressWarnings(cor(d$pred, d$true, method = "spearman"))
  # Weighted kappa requires integer predictions
  d$pred_int <- round(pmin(pmax(d$pred, 0), 3))
  kappa <- tryCatch({
    if (requireNamespace("psych", quietly = TRUE)) {
      psych::cohen.kappa(cbind(d$true, d$pred_int))$weighted.kappa
    } else NA_real_
  }, error = function(e) NA_real_)
  tibble::tibble(model = model_name, n = sum(ok),
                 rmse = round(rmse, 3),
                 mae  = round(mae,  3),
                 spearman_rho   = round(rho,   3),
                 weighted_kappa = round(kappa, 3))
}
```

A note on the baseline's Spearman ρ ≈ -0.62. This counter-intuitive
negative correlation is a known artefact of LOSO-CV when between-
subject variance dominates: the held-out subject's observations are
correlated with their own *true* mean (which is excluded from the
training fold), and the training-fold mean is biased *away* from
the held-out subject's mean. ElasticNet inherits this pattern by
shrinking to baseline; LightGBM's tree splits partially escape it
(ρ ≈ 0).

## 6. Limits, transparency, and the bridge to phase 15d

The honest summary of phase 15c is nuanced. **At n = 44 EMA windows
clustered in 7 subjects, with the public ADARP release restricted to
the Stress Events file rather than the full 4-prompts-per-day EMA
web survey, the physiological feature set extracted in phase 15b
does not yield strong inferential signal at conventional α**. The
MLM in Section 3 found no fixed-effect block significantly improving
over the null random-intercept model with well-defined standard
errors. **However, the predictive ML in Section 4 paints a slightly
richer picture**: while ElasticNet shrinks to the subject-mean
baseline, LightGBM departs from that floor (weighted κ moves from
−0.67 to +0.15, Spearman ρ from −0.62 to ≈ 0), and DALEX permutation
importance places the EDA tonic block (`eda_scl_mean_wz`,
`eda_scl_slope_wz`) at the top of the predictive ranking — a finding
consistent with the autonomic stress literature, where sustained
sympathetic arousal is most reliably reflected in tonic skin
conductance.

The reconciliation between the two tracks is methodologically
informative:

- **MLM tests *whether* a coefficient is non-zero given the model
  structure**. With 44 observations clustered in 7 subjects (between-
  subject ICC ≈ 0.88 on the latent scale), almost all variance in
  the outcome is absorbed by subject identity, leaving very little
  residual to anchor a fixed-effect estimate. This is a power
  limitation, not an absence of biological signal.
- **ML asks *how well* one can recover the outcome from features**,
  with regularisation that depends on the model class. ElasticNet's
  L1 penalty zeros out predictors below an effect-size threshold and
  thus matches the MLM null. LightGBM's tree splits, by contrast,
  can capture local non-linear dependencies that the linear MLM
  cannot see — and the consistency between LightGBM's top features
  (EDA tonic) and the literature suggests the captured signal is
  not a pure overfit.

Three reasons make this combined picture informative rather than
disappointing:

1. **Bounded inference plus a directional hypothesis.** The clmm and
   brms posteriors yield explicit, wide bounds on the magnitude of
   any physio→stress effect at this n. The LightGBM importance
   ranking offers a *directional* hypothesis for which features are
   most worth scaling up the data collection on (EDA tonic,
   secondarily HRV non-linear and HF).
2. **Diagnostic on the data itself.** The outcome ICC ≈ 0.88
   (Section 3.5) and the strong baseline-subject-mean floor in LOSO
   (Section 4) jointly imply that subject identity dominates
   stress-score variance — which is the classic argument for *more
   subjects*, not better features.
3. **Comparison with the dataset's source publications.** Alinia et al.
   (2021), the original team behind the ADARP dataset, performed
   day-level Spearman correlations between EDA/HRV features and self-
   reported stress on the full 343-EMA collection (of which our public
   subset is the 99 stress-flagged events). Their strongest reported
   associations reached |ρ| ≈ 0.34, with most physio-stress correlations
   in the |ρ| ≈ 0.20–0.30 range — modest by absolute standards.
   Importantly, they explicitly identified the absence of multilevel
   modelling as a limitation, noting that "more sophisticated multilevel
   modeling of these associations [...] might provide additional
   insights about within-person associations as well as between-person
   differences." The MLM track of this analysis directly addresses that
   limitation. Our null result at n = 44 is therefore not in conflict
   with the literature: it is the within-subject decomposition of an
   effect that was already known to be weak at the day-aggregated level
   in the full sample.
4. **Pipeline correctness was the deliverable.** Phases 15a–15c
   demonstrate that the full chain — raw multimodal wearable + EMA
   → synchronisation → feature extraction → inference + prediction
   — runs end-to-end with correct method choices, defensible QC, and
   honest interpretation. **That deliverable holds independent of
   the effect-detection magnitude.**


**A note on the binary alternative.** A natural variant of the analysis
would model the binary `stress_event` outcome (rather than the ordinal
composite) with logistic mixed models and AUC-based ML evaluation. We
deliberately did not pursue this for two reasons. First, the public
ADARP release restricts EMAs to the Stress Events file, where prompts
are *triggered by* moments of self-reported stress; the binary outcome
is therefore close to tautological with the act of clicking the EMA
prompt itself. Second, with only 12/92 negative cases (an 80/12
imbalance) clustered in 7 subjects, leave-one-subject-out folds would
contain wildly unbalanced positive/negative ratios, making AUC and
balanced-accuracy estimates extremely unstable at this n. 
Standard remedies for class imbalance — PR-AUC reporting, F1-optimal
threshold selection via nested cross-validation, or class-weight
adjustment in the loss function — would address the metric side of
the problem but not the underlying structural issue: the public
release does not contain the unflagged surveys that would form a
genuine negative class.Re-visiting the binary outcome would require either 
the full 4-prompts-per-day EMA web survey (currently not in the public release)
or a substantially larger cohort.

protocol in addiction medicine, for example
